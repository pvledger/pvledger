Документация PVLedger
=====================

PVLedger — приложение для учёта личных финансов на собственном сервере.
Оно хранит данные о счетах, остатках, доходах, расходах, долгах и налогах
в локальной базе SQLite. Сервер на C++17 предоставляет веб-интерфейс и JSON API.
