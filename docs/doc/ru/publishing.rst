Сборка и публикация документации
================================

Сборка и просмотр
-----------------

Выполните из корня репозитория. Нужны Python 3.11 или новее и Make.

.. code-block:: sh

   python3 -m venv docs/doc/.venv
   docs/doc/.venv/bin/python -m pip install -r docs/doc/requirements.txt
   make -C docs/doc html SPHINXBUILD=.venv/bin/sphinx-build
   python3 -m http.server 8000 --bind 127.0.0.1 --directory docs/doc/_build/html

Откройте `http://127.0.0.1:8000/ <http://127.0.0.1:8000/>`_ и выберите язык.
Исходники находятся в ``docs/doc/en/`` и ``docs/doc/ru/``. Используйте
одинаковые имена файлов для соответствующих страниц, чтобы читатель
мог переключить язык, оставаясь на той же теме. Предупреждения Sphinx
считаются ошибками сборки.

Публикация на статическом хостинге
----------------------------------

Задайте конечный публичный адрес корня документации через
``PVLEDGER_DOCS_URL``, чтобы создать канонические URL.

.. code-block:: sh

   PVLEDGER_DOCS_URL=https://docs.example.org/ make -C docs/doc html SPHINXBUILD=.venv/bin/sphinx-build

Опубликуйте содержимое каталога ``docs/doc/_build/html/`` целиком.
Сервер должен отдавать корневой ``index.html`` и индексные страницы в
``/en/`` и ``/ru/``. Сайт можно разместить в подкаталоге, например
``https://example.org/manual/``. Укажите этот адрес в переменной
окружения. В сборку входят локальный поиск, снимки экрана и справочные
файлы. Для размещения достаточно сервера статических файлов.
