Ход разработки
==============

Версия 0.1.2 (выпущена 26 ноября 2026)
--------------------------------------------------

* Значок PVLedger в области уведомлений Windows, редактор YAML и отдельная
  база SQLite для каждого пользователя.
* Установщики NSIS для Windows x64, сборка через Visual Studio или MinGW-w64.

* Пакеты для Debian, дистрибутивов на базе RPM и Arch, интеграция с systemd и
  SysV init и отдельная учётная запись для службы.
* Прогноз денежных потоков по всем доступным текущим счетам или одному счёту.
* Выгрузка в ODS и XLSX с фильтрами, выбором столбцов и предварительным
  просмотром.
* Резервное копирование и восстановление SQLite в настройках и восстановление
  при первом запуске.
* Изменение остатка при проведении фактических доходов и расходов,
  история остатков текущих и сберегательных счетов.
* При запуске база обновляется до схемы 0.7.3. После резервного копирования
  удаляется поле статуса фактического дохода.
* Графики и таблицы прогнозных остатков по счетам и итогов по валютам.
* Диаграммы распределения остатков текущих и сберегательных счетов по валютам.
* Один вариант QFX в мастере экспорта.
* Коммерческая лицензия наряду с AGPL-3.0-only.
